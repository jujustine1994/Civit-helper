# Civit Helper 規格書

版本：2026-10-18，整合使用者追加需求。使用者已授權審閱後直接實作。

## 目的與完成條件
Windows 個人小工具，使用已安裝的 Google Chrome，在 https://civitai.red/images 每日隨機為 50 張不同圖片按 ❤️，並追蹤 3 位尚未追蹤的不同作者。這是每日任務的操作工具，不承諾獎勵發放，不自動領獎。

## 執行方式
- Windows 工作排程器每天 Asia/Taipei 04:00 隱藏啟動。排程時間包含 +08:00，避免依賴系統時區。
- 僅每天台灣時間04:00自動啟動一次；不設重複、登入觸發或錯過後自動補跑。不喚醒電腦，錯過則等隔天。
- 未完成需由使用者手動補跑；程式額外阻擋04:00倒數時段以外的自動啟動，當日已完成直接退出。
- 中文 Windows 視窗包含立即執行、登入／重新登入、檢查網站（不操作）、查看 log，及分開顯示的當日兩項進度。
- 手動執行可隨時啟動當日任務，和排程共用資料、程式核心及鎖。雙擊啟動檔即可使用。

## 瀏覽器與登入
使用者在首次登入遇到 Google 限制後，明確選擇改用日常 Chrome 擴充功能。主要執行路徑不再啟動獨立 profile 或遠端偵錯。依使用者隱私要求，擴充功能在安裝它的 Chrome 帳號環境建立獨立、最小化的工具視窗，不加入現有視窗的分頁列。記住視窗／分頁 ID 及標記，只操作自己建立的 Civitai 分頁，結束後關閉工具視窗。若使用者增加其他分頁，只關閉工具分頁；歸屬不符時不強制關閉。不修改其他分頁，不讀取 cookie／密碼，不繞過 CAPTCHA。

擴充功能需使用者一次手動透過 chrome://extensions 載入本機 extension 資料夾。權限限 Civitai 網站、本機 127.0.0.1 指定連接埠、scripting、webRequest（只讀觀察網站資料請求）、storage、alarms；不用 debugger、cookies 或所有網站權限。SQLite 核心仍在 Python，藉僅綁定 loopback 且驗證隨機 token 的短期 HTTP bridge 指派有限操作。配對 token 僅存於本機且排除 Git，不傳到網站。

每天04:00顯示180秒倒數通知。按通知關閉或X取消當次；無操作則執行。取消或失敗後不再自動重試，等隔天或由使用者手動補跑。手動不倒數。當日已完成或不在04:00倒數時段不顯示；通知無法顯示則不執行。

「登入／重新登入」在日常 Chrome 開啟 Civitai，讓使用者正常登入；安裝擴充功能後由「檢查網站」確認登入。若 Chrome 尚未開啟，可啟動正常 Chrome，但不關閉或重啟現有 Chrome，不改設定。首次安裝擴充功能需要使用者本人參與。Chrome 關閉或擴充功能未連線須明確回報，不能誤當任務完成。

## 愛心流程
取得圖片及作者候選並打散順序。只對明確尚未按愛心的圖片操作；確認網站接受及重新讀取狀態後才計成功。每次即時保存，當日累計 50 次停止，不額外按愛心。補跑不得取消既有愛心，也不得將本來已按愛心的圖片算為新完成。

## 追蹤流程
優先從瀏覽圖片作者隨機挑選，跳過自己、目前已追蹤的人、重複作者，以及工具曾追蹤的人。每日新增追蹤 3 位，永不取消追蹤。

不足時繼續載入圖片並切換可用排序及時間範圍，擴大作者來源。愛心達標後仍找作者，不額外按愛心。避免反覆掃描同批候選。沒有新內容報告為「搜尋流程停滯／網站限制」，不是「全站沒人可追蹤」。每次最多執行20分鐘，超時仍為未完成，保留進度供當日手動補跑；不自動重試。

## 正確性與故障處理
- SQLite 保存台灣日期、成功圖片 ID、成功作者 ID、待確認操作及執行結果。兩項分開計數，部分完成不能顯示全部完成。
- 操作前寫入意圖；操作後確認保存。中斷或逾時先核對網站；結果不明則保留待確認，不能盲目重按。
- 跨午夜停止本次工作，新日期使用新進度。程序鎖隨程序結束自動釋放。
- 網路失敗、頁面變更、載入停滯、登入失效及人工驗證分開回報。有限重試，不無限忙等。
- 綁定首次確認的帳號，切換帳號停止，避免進度混用。

## 紀錄與資料
每日輪替文字 log，保留 30 天，包含時間、來源、執行 ID、兩項成功數、作者／圖片識別碼和錯誤原因，不記錄登入機密。profile、資料庫及 log 排除版本控制。顯示「尚未登入／待驗證／部分完成／完成」。

## 技術與交付（實作者決定）
Python 3.13、SQLite、Tkinter、Chrome Manifest V3 擴充功能；既有 Playwright adapter 僅保留測試參照。虛擬環境位於 C:/Users/CTH/venvs/CivitHelper。提供 GUI 隱藏啟動入口及 run、login、inspect、status 命令列模式，排程安裝與移除腳本。繁體中文 README 說明擴充功能載入、登入、排程及故障恢復。

## 驗證與限制
先只讀檢查登入、圖片資料、按鈕和狀態，再透過網站操作確認成功，不只看點擊事件。測試持久化、續跑、互斥、跨日、重試、無新候選及結果恢復。現行網站相容性須登入後實測。需要使用者登入時集中交代步驟，不索取密碼。網站不可用仍交付登入、診斷、log、GUI 及排程，明確標示網站尚未實測，不誤稱任務完成。
